# picsure: R Client for the PIC-SURE API

Thin R wrapper over the PIC-SURE Python adapter. Provides functions to
connect to PIC-SURE networks, search the data dictionary, build nested
query clauses, run queries, and export results. Python interop is
handled transparently via reticulate; the required Python environment is
provisioned automatically on first use.
